# 86Box Manager - Wizard Edition

A modern, sleek virtual machine manager for 86Box, built from the ground up using C# and WinUI 3. The Wizard Edition brings a refined user interface and streamlined workflow to your retro computing and emulation experience.

## ✨ Features
* **All-in-One Executable:** Comes bundled with the 86Box emulator files ready to go.
* **Modern Interface:** A clean, responsive design powered by WinUI 3 and XAML.
* **Streamlined Management:** Easily configure, launch, and manage your retro virtual machines.

## 🚀 Getting Started

### Prerequisites
* Windows 10 or Windows 11
* **86Box ROMs:** Due to copyright, ROM/BIOS files are *not* included. You will need to provide your own `roms` folder.

### Installation & Run
1. Download the latest release.
2. Extract the files to your preferred directory.

## 🛠️ Built With
* C#
* WinUI 3 / Windows App SDK
